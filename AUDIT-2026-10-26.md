# Аудит редактора, 26 октября 2026

Релиз: 1.13.0. Проверены 19 автоматических наборов. Подключённого браузера не было;
визуальная проверка и фактическая публикация в Genially не выполнены.

## Найдено и исправлено

- Один финальный файл 12 МиБ в base64 превышал старый общий предел 16 000 000 байт.
  Единый предел данных увеличен до 64 МиБ. Он действует и на распаковку.
- Проект с несколькими медиа можно было сохранить, но не открыть из-за лимита
  импорта 20 МиБ. Импорт и сохранение теперь ограничены одинаковыми 64 МиБ.
- В раскладке дублировались вложения вопросов. При сохранении остаются координаты,
  а вложения хранятся в списке слов. Качество файлов не меняется.
- Открытие другого проекта могло оставлять фон и настройки предыдущего проекта.
  Теперь используются сохранённые настройки и исходные значения редактора.
- Не было проверки типа аудиофайла при загрузке. Теперь принимаются MP3 / OGG.
- По одному можно было добавить более 100 слов. Предел теперь одинаков для ввода
  по одному и для списка.
- История отмены могла содержать сто полных копий больших проектов. Введён бюджет
  памяти истории; для больших проектов доступно меньше шагов отмены.
- `?v=` только менял кэш, но не сохранял движок. Новые игры указывают каталог
  `releases/1.13.0`. Старые ссылки направляются на соответствующие архивы.
  Сохранены 22 ранее опубликованные версии, начиная с 1.2.0.
- Старые большие iframe 1.12.1 продолжают получать свою версию скриптов.
  Автономный HTML уже содержит движок внутри и не зависит от обновлений редактора.

## Фактические проверки

| Проверка | Результат |
| --- | --- |
| Изображение финала ровно 12 МиБ | загрузка, байты сохранены |
| Аудиофайл вопроса ровно 8 МиБ | чтение и перенос байтов, размер сохранён |
| Файл на один байт больше ограничения | отклонён, старое вложение сохранено |
| 2 изображения по 12 МиБ и аудио 8 МиБ одновременно | экспорт iframe, запуск, окно аудио, сохранение и повторный импорт прошли |
| JSON ровно 64 МиБ | сжатие и распаковка прошли |
| JSON 64 МиБ + 1 байт | отказ в кодировании, plain- и deflate-декодировании |
| 100 вопросов со 100 аудиовложениями | движок и список с иконками запускаются |
| Сохранённые движки 1.2.0, 1.11.10, 1.12.1, 1.13.0 | старый формат данных запускается |
| Маршрутизация ранее опубликованных версий | адрес и фрагмент с проектом сохраняются |
| Изменение проекта после экспорта | ранее созданный код содержит прежние вопросы и настройки |
| Генерация, цвета, размеры текста, клавиатура, финалы, импорт, Undo/Redo | основные наборы проходят |
| PNG и анимированные GIF при экспорте | пиксели / исходные байты сохранены |

Нагрузочные вложения синтетические. Проверка доставки MP3 не подтверждает
декодирование или слышимость конкретного файла на телефоне. Для этого нужен браузер.

## Действующие ограничения

- До 100 слов. Картинка или аудио вопроса — до 8 МиБ за файл.
- Фон, свой персонаж и каждая финальная картинка — до 12 МиБ за файл.
- Общий JSON игры/проекта — до 64 МиБ, включая base64 и настройки; это примерно
  до 48 МиБ уникальных бинарных вложений при небольшом объёме остальных данных.
  Повторы вложений и шрифты также занимают место. Это не 64 МиБ исходных файлов.
- Прямая ссылка ограничена 2 000 000 символов. Большая игра получает код srcdoc,
  а не прямую ссылку. Сжатие без потерь не может существенно уменьшить уже сжатые
  фотографии или MP3. Ограничения поля Genially могут не пропустить большой код;
  в этом случае нужен размещённый HTML и короткий iframe с его адресом.
- Новые ссылки и архивы движков требуют доступности GitHub Pages. Каталоги releases
  и используемые ассеты нельзя удалять при будущих публикациях. Автономный HTML
  работает независимо от доступности сайта редактора.
