# Studio 1.7

В разделе «Проект» добавлены две независимые галочки:

- «Оставить титульный лист в игре»: определяет наличие стартового экрана в игре для учеников, автономном HTML и Genially. По умолчанию включена. При выключении сразу видна игровая сетка.
- «Скрыть титульный лист только в редакторе»: временно открывает сетку для редактирования, сохраняя титульный лист в игре. По умолчанию включена, чтобы сохранить прежний вид рабочего холста.

Режим «Тестировать» показывает поведение игры для игрока и не использует вторую галочку. Настройка редактора сохраняется в проекте, но не включается в HTML и iframe-ссылку. Старые проекты и ссылки по умолчанию сохраняют титульный лист.

`tests/start-screen.test.cjs` проверяет все четыре комбинации галочек, различие между редактированием и тестированием, сохранение проекта, экспорт с титульным листом и без него, отмену и повтор. Визуальная проверка в браузере и Genially недоступна в этой сессии.
