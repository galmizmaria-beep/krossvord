# Кроссворд Studio

Редактор учебных кроссвордов с интерфейсом Studio и холстом 16:9. Прозрачный фон, цвета вопросов, их подложки и клавиатуры настраиваются отдельно. Кот из предоставленного пользователем примера — прозрачный GIF из 50 кадров. Собственные GIF можно назначать девяти игровым состояниям.

**Версия 1.8:** [Comic и его начертания](STUDIO-1.8.md). [Титульный лист](STUDIO-1.7.md), [шрифты и медиа вопросов](STUDIO-1.6.md), [галерея персонажей](STUDIO-1.5.md), [автосжатие](STUDIO-1.4.md), [холст 16:9](STUDIO-1.3.md).

## Запуск

Не нужен сервер приложения, аккаунт или сборка. Для локального запуска:

```sh
cd krossvord
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. Небольшой локальный HTTP-сервер необходим для чтения встроенных ассетов во время сборки экспорта. Уже экспортированная HTML-игра открывается напрямую и работает офлайн.

## Возможности

- Ввод слов и вопросов, дополнительные подсказки, объяснения, категории, индивидуальные баллы, изображения и аудио вопросов.
- Массовая вставка и импорт TXT/CSV: `СЛОВО; Вопрос` или `СЛОВО — Вопрос`.
- До пяти разных вариантов раскладки: ранжирование по числу размещённых слов и компактности, миниатюры, список неразмещённых слов.
- Размер рабочей сетки 5–40. Ручное размещение координатами или перетаскиванием слова на поле; проверка границ, пересечений и соседства.
- Цвета, фон, радиусы, типографика отдельных элементов, пользовательские WOFF/WOFF2.
- Физическая и экранная клавиатуры, переключение направления, проверка, подсказки, жизни, таймер, баллы, победа/поражение/тайм-аут, повтор игры.
- Кот с настраиваемыми репликами, размером, отражением и изображениями/GIF состояний.
- Undo/Redo, IndexedDB-черновик, скачивание и восстановление JSON-проекта вместе с медиа.
- Автономный HTML без внешних скриптов, шрифтов и изображений, минифицированный игровой движок, iframe-код для Genially.
- Высокий контраст, уменьшение анимации, focus-ring, подписи клеток для экранного диктора.

## Экспорт и Genially

Нажать «Экспорт игры» → «Скачать HTML-игру». Файл содержит всю игровую логику и изображения; панели редактора и подписи об авторских правах в игре нет.

Для Genially загрузить экспортированную HTML-игру на GitHub Pages или другой статический хостинг. В разделе Genially вставить полученную ссылку и скопировать iframe. Ссылка должна указывать на **игру**, а не редактор. Скопированный HTML можно использовать в среде, разрешающей собственные скрипты. Доступность произвольного HTML в конкретном аккаунте Genially редактор не проверяет.

PNG/JPEG/WebP при загрузке уменьшаются и преобразуются в WebP с прозрачностью. GIF сохраняется без потери анимации; его кадры и палитра в этой версии не перекодируются. При превышении ориентировочного порога 8 МБ экспорт предупреждает о размере.

## GitHub Pages

Содержимое `dist/` можно разместить в корне репозитория GitHub Pages. Зависимости и сборка для публикации не нужны. Все пути относительные, поэтому редактор поддерживает размещение в подпапке репозитория. JSON-черновик хранится только в браузере и не отправляется на сервер.

## Разработка и проверки

Node.js 22+:

```sh
npm install
npm test
npm run build
```

`npm run build` безопасно минифицирует `engine.js` и `game.js` в версии для экспорта. После изменений движка или игры обязательно пересоздать `.min.js`. Исходные файлы остаются читаемыми.

Автоматические проверки: 100 раскладок из 20 слов, конфликты, границы и учёт всех слов; навигация разделов, варианты, редактирование, Undo/Redo, старт, ответы, подсказки, жизни, поражение, повтор и выполнение экспортированного HTML в DOM-среде. Встроенный браузер был недоступен в среде разработки; визуальная проверка и реальная проверка в Genially не выполнялись.

Состояние покрытия полного ТЗ и оставшиеся расширения — в `АНАЛИЗ_ТЗ.md`. Промпты и происхождение иллюстраций — в `ASSETS.md`.
