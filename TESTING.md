# Проверка редактора

`npm test` запускает 19 наборов проверок: генерация, настройки, ввод и редактирование,
импорт, шрифты, клавиатура, персонажи, финалы, медиа, автономный HTML, встраивание,
нагрузка и совместимость. Для запуска нужны Node и зависимости из package.json.

`npm run build` создаёт минифицированный движок и сохраняет опубликованную версию
в `dist/releases/<version>`. Изменять существующую версию нельзя: сначала повышается
номер версии. Существующие каталоги releases необходимо сохранять при публикации.
Сборка проверяет неизменность общих ассетов по SHA-256; для изменённого изображения
нужно новое имя файла. Это сохраняет работу ранее опубликованных игр.

Нагрузочные данные синтетические: проверяются байты и доставка вложений, а не
декодирование произвольного MP3 браузером. Отдельно проверяются реальные PNG и GIF.
Звуковое воспроизведение, мобильная вёрстка, буфер обмена и вставка в конкретный
опубликованный Genially требуют браузерной проверки.

Перед уроком:
1. Изменить проект, сохранить JSON и открыть его снова.
2. Пройти игру: правильный/неверный ответ, подсказка, три финала.
3. Открыть картинку и аудио; проверить крестик и остановку аудио.
4. Скачать HTML и запустить без сети.
5. Создать код Genially и проверить в опубликованной презентации.
6. Проверить экранную клавиатуру и читаемость на телефоне.

Игра по сохранённой ссылке или коду содержит снимок вопросов и настроек. Изменения
проекта в редакторе туда автоматически не переносятся: требуется новый экспорт.
Небольшие игры получают ссылку на сохранённый движок. Большие игры — iframe srcdoc.
Лимит редактора на прямую ссылку — 2 000 000 символов; лимиты браузера и внешней
площадки могут быть ниже. Сам факт выдачи кода не подтверждает принятие его Genially.
