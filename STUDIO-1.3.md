# Studio 1.3

- Единый холст 1280 × 720 (16:9) в редакторе, предпросмотре, автономном HTML и проигрывателе для Genially. `stage.js` масштабирует весь холст пропорционально доступному окну и отдельно вписывает сетку в её область. При открытии клавиатуры сетка получает оставшееся пространство.
- Iframe объявляет ширину 1280 и высоту 720. В Genially установите блоку размеры слайда и координаты X = 0, Y = 0. Содержимое iframe не может управлять размером родительского объекта в редакторе Genially.
- Убраны нижняя картинка с листвой, декоративные листья и текстовый нижний колонтитул игры. Старый `botanicalAsset` не используется и не включается в экспорт.
- В разделе «Дизайн»: прозрачный фон игры; текст, фон и прозрачность подложки вопроса; цвет клавиш, букв и подложки клавиатуры. Все настройки сохраняются в проекте, ссылке и автономной игре. Шахматная подложка обозначает прозрачность только в редакторе и не экспортируется.
- Стартовый и финальный экраны поддерживают прозрачность; скрытый игровой интерфейс не просвечивает через них.

## GIF

Текущий персонаж взят из предоставленного пользователем примера https://storage.yandexcloud.net/chefs-kiss-english.ru/Plurals/index.html. Это рисованный анимированный кот, а не новый 3D-рендер. Оригинальный GIF: https://img.genially.com/66f3a31bcd1a12001568ab85/90352b25-74f0-4a30-9c32-f4294517e1a8.gif.

Файл скопирован без изменения: 713 × 595, 50 кадров по 100 мс, 5 секунд, бесконечный цикл, прозрачность всех кадров. `dist/cat-assets.js` содержит встроенные GIF и неподвижный первый кадр. Он подключён в редакторе и проигрывателе, поэтому картинке не нужен отдельный запрос к внешнему CDN. Автономный HTML включает те же данные в проект. `scripts/bundle-cat.cjs` пересобирает этот пакет из файлов assets.

Предыдущие сгенерированные варианты заменяются при загрузке проекта по известным хешам. Пользовательские изображения сохраняются. Остановку анимации можно явно включить в разделе кота; сброс персонажа включает анимацию.

## Проверка

Автотесты проверяют геометрию холста, отсутствие ботанической картинки, настройку и экспорт цветов/прозрачности, встроенный GIF, переключение его паузы, запуск игры из сжатой ссылки и автономного HTML. GIF проверен на количество кадров и циклическое воспроизведение по структуре файла.

Визуальная проверка браузером и непосредственная вставка в Genially недоступны: Browser возвращает пустой список подключённых браузеров. Эти проверки не заменяются JSDOM.
